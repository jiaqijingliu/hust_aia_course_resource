使用说明：
需要先建个工作目录，然后解压代码到**另一个地方**，然后import导入项目。

工作目录需要放入v125文件，然后配置一下包含的头文件。见文档：

1） 设置Includes

MyNewPrj，鼠标右键，最下面“Properties” ->Build ->C2000 Compiler ->Include Options

```
添加两个路径，<>中的请替换为自己的，去掉<>.
<F:\DSP2025>\V125\DSP2802x_common\include
<F:\DSP2025>\V125\DSP2802x_headers\include
```



代码说明，字符编码用的GB2312，因为那个CCS默认是这个，使用VSCODE插件即可轻松修改打开方式，就不改成UTF-8了。部分接线、等接口选择需要根据指导书中的引脚接线等。

代码还有很多不明的变量定义（但没删去）。代码主要来源（祖传？）+部分地方自己改写+修bug+删除部分不明意义代码+注释理解

以下代码均经过验证，没有功能实现上的问题。

**项目1**

需要注意下面的上拉电阻，这个很奇怪，原本板子写0是对的，换板子就得写1 。

```
void Xint1_Init()
{
    EALLOW;                                  // 关闭写保护，允许修改受保护寄存器
    SysCtrlRegs.PCLKCR3.bit.GPIOINENCLK = 1; // 使能GPIO输入时钟
    GpioCtrlRegs.GPAMUX1.bit.GPIO12 = 0;     // 配置GPIO12为普通数字IO功能
    GpioCtrlRegs.GPADIR.bit.GPIO12 = 0;      // 输入方向
    GpioCtrlRegs.GPAPUD.bit.GPIO12 = 1;      // 使/禁能上拉电阻，看板子情况
```
